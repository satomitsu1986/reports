APPENDIX A / 複業.Lab

副業・起業開発の詳細

企業向け

  • 社員の経験・Skillから可能性を発見
  • 小さな外部Experiment
  • 越境学習・Career Autonomy

地方自治体向け

  • 住民の副業・起業仮説
  • 地域企業の小さな課題と接続
  • 地域で試し、結果から学ぶ

蓄積する知見

どんな状況の人が、どんな一歩から新しい仕事を育てたか。単なる職歴ではなく、形成過程を理解する。

境界

Generic Talent Managementや求人Marketplaceを主目的にしない。効果は検証前に断定しない。

APPENDIX B / BDX

Conditioning支援の詳細

Ballet Method

Training、Recovery、Nutrition、Sleep、Mental、日々のCondition Managementを含む。

日常での体験

  • MOVE：身体を動かす
  • LEARN：身体・心・生活を学ぶ
  • CARE：休み、整える

連携先の役割

Trainer / TeacherがTraining、Lesson、専門判断を担う。BDXはその外側の日常を支える。

学びたいこと

どんな状態で、どんな行動をすると、次のConditionがどう変わる可能性があるか。

APPENDIX C / Cafe

Artist支援の詳細

Discovery

Artistを探していなかった来店者が、日常の中で偶然知る接点をつくる。

Growth

Audienceの反応から、新しい見せ方・活動・Audience・仕事を発見する可能性をつくる。

Event Company

企画・制作・会場・販売・運営は連携先が担う。Cafeは出会いとArtist理解を持ち寄る。

Data方針

Supporter Dataの販売を目的にしない。どんな出会いが支援と成長につながるかを学ぶ。

APPENDIX D / TRUST

データ利用の原則

原則判断意味
User Firstまず一次事業を改善行動と結果から得た学びは、最初に本人への価値へ戻す。
No Raw Data Sale個人データを商品にしない知見をMethod、Product、Programへ変換する。
Consent本人の明示的同意必要な外部共有は、目的を明示し、本人が選べる設計を前提とする。
Domain Separation3事業を自動統合しない各領域のデータは原則分離し、Super App化しない。

データもAIも目的ではない。
人への価値を、より良く届けるための手段。
