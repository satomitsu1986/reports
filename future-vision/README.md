# 3事業 長期構想

複業.Lab、BDX、Cafeの一次事業で生まれた価値を、データ・知見・ノウハウへ変え、パートナーとの二次事業を通じて社会へ広げる長期構想資料です。

## 構成

本編は10章です。

1. 長期構想
2. 成長構造
3. 事業資産
4. 複業.Lab
5. BDX
6. Cafe
7. パートナーシップ
8. 社会価値
9. 移行条件
10. 価値の最大化

本編の後に、現在と将来、データ利用、対象外を整理したAppendixが3ページあります。

## 会社の思想

`価値の最大化`

一次事業で一人に生まれた価値を、知見へ変え、方法へ変え、パートナーとともに社会へ広げます。

## 二次事業

- 複業.Lab × 企業・地方自治体：副業・起業開発支援
- BDX × フィットネスクラブ・バレエスクール：日常コンディショニング支援
- Cafe × イベント会社：アーティスト発見・成長支援

## 資料の位置づけ

本資料は長期的な事業構想です。パートナーとの契約、価格、効果、導入時期を確定事項として示すものではありません。3事業の統合や個人データ販売も目的としていません。
