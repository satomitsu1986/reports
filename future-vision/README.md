# 3 Business Future Vision v2.0

複業.Lab、BDX、Cafeの3事業が、一次事業の実践から得るLearningを使ってProductを改善し、十分な実績と再現性ができた領域からPartnerと届け方を広げるFuture Vision資料です。

## Files

- `index.html`: 18ページ構成のHTML版。ブラウザ閲覧とA4横PDF出力に対応。
- `notes.md`: 資料の前提、確定事項、将来仮説、Privacy上の注意、出典を整理。

## Core Message

`BUILD → LEARN → PROVE → EXPAND`

3つのB2C事業でユーザー価値を証明し、実践から得た知見とPartnershipによって、企業・地域・既存施設へ展開する。

「Goalは変えない。届け方を広げる。」は、この事業成長を進める際の原則として扱います。

## Print

ブラウザの印刷機能で「A4・横向き」「背景グラフィックを表示」を選ぶと、各Sectionが1ページとして出力されます。

本資料はVision Documentです。企業、地方自治体、Fitness Club、Ballet School、Event Companyとの契約や効果を確定事項として示すものではありません。
