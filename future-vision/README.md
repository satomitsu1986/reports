# 3事業 Future Vision v3.0

複業.Lab、BDX、Cafeの3事業が、現実の行動と結果から学び、十分な実績と再現性ができた領域から外部連携によって価値を広げる事業構想資料です。

## Files

- `index.html`: 本編17ページ、Appendix 4ページのHTML版。ブラウザ閲覧とA4横PDF出力に対応。
- `notes.md`: 資料の前提、確定事項、将来仮説、Privacy上の注意、出典を整理。
- `redesign-report.md`: v2.0からv3.0への情報設計・文字量・検証結果を記録。

## 資料の背骨

- WHY: `可能性を、現実の一歩から育てる。`
- HOW: `行動 → 反応 → 学習 → 成長`
- GROWTH: `つくる → 学ぶ → 証明する → 広げる`

本編は1ページ1メッセージで構成し、詳細な事業判断やデータ利用方針はAppendixへ分離しています。

## 印刷

ブラウザの印刷機能で「A4・横向き」「背景グラフィックを表示」を選ぶと、各Sectionが1ページとして出力されます。

## 資料の位置づけ

本資料は将来の事業構想です。企業、地方自治体、フィットネスクラブ、バレエスクール、イベント会社との契約や効果を確定事項として示すものではありません。3事業の統合や個人データ販売も目的としていません。
