# 3事業 成長構想 v2.0

複業.Lab、BDX、Cafeの3事業が、個人向け事業の実践から得る知見を使ってサービスを改善し、十分な実績と再現性ができた領域から外部連携によって届け方を広げる事業構想資料です。

## Files

- `index.html`: 13ページ構成のHTML版。ブラウザ閲覧とA4横PDF出力に対応。
- `notes.md`: 資料の前提、確定事項、将来仮説、Privacy上の注意、出典を整理。

## 中心構造

`つくる → 学ぶ → 証明する → 広げる`

3つの個人向け事業で利用者への価値を証明し、実践から得た知見と外部連携によって、企業・地域・既存施設へ展開する。

「目的は変えず、届け方を広げる。」を、この事業成長を進める際の原則として扱います。

## 印刷

ブラウザの印刷機能で「A4・横向き」「背景グラフィックを表示」を選ぶと、各Sectionが1ページとして出力されます。

## 資料の位置づけ

本資料は将来の事業構想です。企業、地方自治体、フィットネスクラブ、バレエスクール、イベント会社との契約や効果を確定事項として示すものではありません。
