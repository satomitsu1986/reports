01 — Project Overview

プロジェクト概要

BDXは、運動を始めても続かない一般ユーザーに向けて、身体の使い方、動く楽しさ、日々の選択支援を一つの体験として提供します。

課題と解決策

PROBLEM

正しい情報があっても、運動は続かない

  • 自分の体調や時間に合う運動を選べない
  • 忙しさや疲労で生活に組み込めない
  • 成果を感じる前に中断してしまう
SOLUTION

今日の自分に合う行動を、選びやすくする

  • 短時間で実行できる運動を提案する
  • 体調と行動を記録し、変化を振り返る
  • 専門コンテンツとAIで継続を支える

04 — Why Ballet

なぜバレエなのか？

バレエを習得するためではなく、姿勢、重心、バランス、動作の精度を扱う身体メソッドを、一般ユーザーの体調管理へ応用するためです。

01

身体を細かくコントロールする

バレエでは、姿勢、重心、関節の位置、動作の方向などを意識しながら身体を動かす。BDXでは、この身体認識の考え方を初心者向けに再設計する。

02

しなやかさと強さを同時に扱う

柔軟性だけ、筋力だけではなく、可動性、安定性、バランス、動作の精度を組み合わせて身体を使う。

03

日常動作にもつながる基礎を育てる

立つ、支える、伸びる、重心を移すといった基本動作を丁寧に扱い、身体をコントロールする感覚を育てる。

BDXはバレエの技術習得を目的とするのではなく、バレエに含まれる身体の使い方を、一般ユーザー向けフィットネスへ翻訳します。
05 — AI Features

AIの機能

AIはトレーナーの代わりではありません。ユーザーの状態、行動履歴、BDXの専門コンテンツをつなぎ、今日実行できる選択肢を整理する機能です。

01

今日の状態を確認する

睡眠、疲労、痛み、気分、使える時間などを短時間で記録する。

02

実行可能なメニューを選ぶ

理想的なメニューではなく、今日の状態で実行しやすい内容を提案する。

03

行動を記録する

実施内容、感想、負荷、体調変化を蓄積する。

04

次の提案へ反映する

過去の履歴を使い、次回の提案や声かけを調整する。

提案の仕組み

1. User Input
  • 目的・運動経験
  • 使える時間
  • 睡眠・疲労・気分
  • 痛み・違和感
  • 行動履歴
2. BDX Knowledge
  • 監修コンテンツ
  • ワークアウト情報
  • 難易度・所要時間
  • 禁忌・注意事項
3. Recommendation
  • 目的と当日の状態
  • 過去の実施状況
  • 安全上の制約
  • 継続可能性
4. Output
  • 今日の提案と理由
  • 代替メニュー
  • 注意事項
  • 振り返り質問

安全設計

中止を案内する

痛みや傷害が疑われる場合は、運動の中止と専門家への相談を案内する。

医療判断を行わない

診断や治療方針を決定せず、必要に応じて医療機関の受診を案内する。

選択を強制しない

提案は変更・拒否でき、高負荷の運動を自動的に推奨しない。

理由を説明する

提案理由と注意事項を、可能な範囲で分かりやすく示す。

AIは医療診断、治療、痛みや傷害の安全性保証、専門家による個別評価やオンラインLive指導を代替しません。
