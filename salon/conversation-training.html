00

PURPOSE

この講義で目指すもの

失礼がない、丁寧、感じがいい。それは最低条件。そこから一歩進んで、「この人には話したくなる」「また会いたい」と思われる美容師を目指します。

この資料では、相手の反応を読みながら心の距離を縮める接客を「攻めの接客」と呼びます。

GOAL

最終ゴールは、相手が自然と心を開き、本音や感情まで深く共有できる親密な関係をつくること。

01

WHY IT MATTERS

守りの接客から、攻めの接客へ

丁寧に話す。失礼なことを言わない。お客様を不快にさせない。もちろん大切です。ただ、それだけでは「悪くない美容師」にはなれても、「また会いたい美容師」にはなりにくい。

守りの接客

  • 失礼をしない
  • 無難な会話
  • 相槌で終わる
  • 問題がなければ成功

攻めの接客

  • 記憶に残る
  • 相手そのものに興味を持つ
  • 一歩深める
  • また会いたいまで作る

NG｜守りだけで終わる

お客様最近仕事忙しくて。

美容師そうなんですね。大変ですね。

→ 問題はない。でも、関係性はほとんど進んでいない。

OK｜一歩だけ入る

お客様最近仕事忙しくて。

美容師それ結構しんどそうですね。ずっと忙しいんですか？

お客様最近、人が辞めちゃって……。

→ 相手が開けた扉から一歩だけ入っている。

RULE

攻めるのは相手の境界線ではなく、関係性。

02

MINDSET

会話は才能ではない

「自分は会話が苦手だから」で終わらせる必要はありません。会話もカットと同じ。型を知り、実践し、反応を見て修正することで上達します。

SELF FOCUS

自分に意識が向いている

  • 「何話そう……」
  • 「沈黙になったらまずい」
  • 「面白いこと言わなきゃ」

この状態では、「自分がどう見られるか」「次に何を言うか」「失敗しないか」に意識が向いています。相手を見ているようで、実際には自分自身を見ています。

OTHER FOCUS

相手に意識が向いている

  • 「今日は何を話したいんだろう？」
  • 「今はどんな気分なんだろう？」
  • 「今の話題になったら急に態度が変わったな」

会話が上手い人は、自分の話題を探すよりも、相手の反応を観察しています。「何を言うか」ではなく、「相手の中で何が起きているか」に注意を向けます。

お客様自身も「今日は仕事の悩みを美容師に深く話そう」と決めて来店しているわけではありません。だから美容師側が、軽い話題を投げながら、本人もまだ意識していない「話したいこと」を一緒に見つけていきます。

KEY MESSAGE

話題を考えるな！
相手が話したい話題を探せ！

深い話を無理に取りに行くのではありません。安心・好奇心・共感を積み重ねた結果、本人も予定していなかった深い話に自然と入っていく。

それが攻めの接客です。

03

GOAL

ゴールは「感情を深く共有できる関係」

会話のゴールは、話を盛り上げることではない。

相手が自然と心を開き、感情や本音まで共有できる関係になること。

レベル
共有するもの
1
事実：沖縄に行った
2
経験：海が良かった
3
考え：旅行ではゆっくりしたい
4
感情：友達と久しぶりに行けて嬉しかった
5
本音：最近疎遠で寂しかった

ULTIMATE GOAL

「実は誰にも言ってないんだけど……」「ちょっと相談していい？」が自然に出る関係。無理に聞き出すのではなく、相手が自分から話したくなる状態をつくる。

自分の話を聞いてくれる。理解してくれる。共感してくれる。意見が違っても否定されない。だから、もっと話したくなる。

04

THE LOOP

会話の全体モデル

会話は一方向に深め続けるものではありません。入口を作り、反応を見ながらつながりを探し、必要なら戻る。この流れを繰り返すことで、相手のペースを守りながら関係を積み重ねます。

05

ENTRY

会話で一番困ることは「最初に何を話すか」

入口をいくつか持っておけば、毎回ゼロから考える必要はありません。基本は3つです。

入口
使い方
髪の雑談
最も自然。会話温度も測れる
前回の続き
既存客との関係を積み重ねる
自分の出来事
自己開示しながら新しい話題を作る

HAIR TALK

カウンセリングと、髪の雑談は別

「今日はどうします？」「何センチ切ります？」「カラーはどうします？」

これらは施術を決めるためのカウンセリングです。もちろん必要です。

ただし、カウンセリングが終わったからといって、髪の話題が終わるわけではありません。

美容師とお客様には最初から、「髪」という共通テーマがあります。これは初対面でも使える、最も安全な雑談の入口です。

髪の雑談の例

  • 「髪の毛で何か悩みあります？」
  • 「髪型を参考にしてる人っています？」
  • 「自分の髪で気に入ってるところあります？」
  • 「昔やってた髪型で、もう一回やりたいのあります？」
  • 「自分の髪質って好きです？」
  • 「今までで一番気に入ってた髪型ってあります？」

会話例

美容師髪型って普段Instagramとかで探します？

お客様結構見ます

美容師誰か参考にしてる人います？

お客様○○ちゃんとか

美容師ああ、ああいう雰囲気好きなんですね。服もああいう感じ好きです？

ここで、髪 → 好きな芸能人 → ファッション → 好み と自然に広がっています。

POINT

髪の話は、髪の話を続けるためだけに使うのではない。その人の好み・価値観・ライフスタイルへ入る入口として使う。

また、髪の雑談に対する反応を見ることで、その日の会話温度も分かる。

06

REMEMBER

既存客は「前回の続き」から始める

既存客に毎回ゼロから話題を探す必要はありません。前回の会話を覚えていること自体が、「あなたを一人の人として覚えています」というメッセージになります。

NG｜毎回リセット

美容師最近どうですか？

お客様まあまあです。

→ 関係が積み上がりにくい。

OK｜前回を回収する

美容師この前言ってた旅行どうでした？

お客様めっちゃ良かったです！

美容師よかった。前に海が目的って言ってましたけど、どうでした？

→ 前回の記憶が、親密さそのものになる。

POINT

会話を「点」で終わらせず、「線」にする。

07

SHARE → ASK

自分の出来事を「話題の種」にする

映画、行った場所、食べたもの、最近始めたこと、ちょっとした失敗。自分の体験を入口にしてもいい。ただし、自分語りではなく「話題の種」として使います。

NG｜そのまま自分語り

美容師この前映画行ったんですけど、その前にご飯食べて、それから映画館で……

→ 相手が入る余地がない。

OK｜Share → Ask

美容師この前○○って映画観たんですけど、結構面白かったんですよ。○○さん映画観ます？

お客様結構観ます。

美容師どんなの好きなんです？

→ 自分を少し出したあと、相手に返している。

HOST

美容師の話を聞きたい人、自分の話をするのが苦手な人もいる。だから美容師がホスト役になり、話題を出し、答えやすくし、相手のペースを作る。

08

SEARCH

序盤は「話題探索」

最初の話題を一発で当てる必要はありません。軽く投げて、反応の良いテーマを探します。ラジオの周波数を合わせるようなものです。

最初から深い話題を当てようとすると、会話を外した時に焦りが生まれます。序盤の目的は盛り上げることではなく、いくつかの軽い話題を試しながら「この人は何に反応するか」を知ることです。

言葉の内容だけでなく、回答の長さ、表情、声の変化、質問が返ってくるかまで見ます。反応が変わった場所が、その日の会話を育てる入口になります。

• 回答が長くなる

• 自分から情報を足す

• 表情や声のトーンが変わる

• 質問が返ってくる

• 同じ話題を続けようとする

NG｜反応が薄いのに押す

美容師旅行好きなんですか？

お客様いや、あんまり。

美容師海外は？

お客様行かないですね。

美容師国内だったら？

→ 反応していない話題に執着している。

OK｜違ったら切り替える

美容師旅行とか行きます？

お客様あんまり行かないですね。

美容師そうなんですね。

→ 捨てる勇気も会話力。別の入口へ移る。

RULE

最初の会話は「話題づくり」ではなく「温度測定」。

09

SIGNAL

質問されたら、一度同じテーマで返す

相手からの質問は重要なシグナルです。本当に美容師の話を聞きたい場合もあるし、自分もそのテーマを話したい場合もあります。答えたあと、一度返して確認します。

質問を受けると、つい詳しく答えたくなります。しかし、相手がそのテーマを自分から出したことには意味があります。短く答えて同じテーマを返すと、相手が聞き役を望んでいるのか、自分も話したいのかを確かめられます。

NG｜相手の入口を独占する

お客様旅行とか行くんですか？

美容師めっちゃ行きます。この前韓国行って、その前はタイで……

→ 相手が開いたテーマを美容師が独占している。

OK｜答えて返す

お客様旅行とか行くんですか？

美容師行きますよ。この前韓国行きました。○○さんも旅行好きなんですか？

お客様実はこの前沖縄行ったんですよ！

→ 「旅行の話をしたかった」可能性が見えてくる。

IF–THEN

質問されたら、答えたあと同じテーマで一度質問を返す。

10

CONNECT

雑談では「共通点」を探す

共通点が見つかると、会話は一気に楽になります。趣味、出身地、音楽、映画、食、旅行、子育て、仕事、価値観。何でもいい。

共通点の価値は、話題が増えることだけではありません。「自分と似ている」「分かってもらえそう」という安心感が生まれ、相手が次の話をしやすくなります。

ただし、共通点が見つかった瞬間に自分の話へ奪わないこと。まず相手の話を広げ、その後で自分の経験を少し重ねると、共通点が関係をつなぐ橋になります。

NG｜共通点を捨てる

お客様ホラー映画好きなんです。

美容師へえ、そうなんですね。

→ せっかくの接点を使っていない。

OK｜共通点を橋にする

お客様ホラー映画好きなんです。

美容師僕も好きです。どんな系が好きなんです？

お客様幽霊じゃなくて、人間の怖さが描かれる作品です。

美容師ああ、人間が一番怖いやつですね（笑）

→ 「同じ」が生まれると、会話が自然に加速する。

POINT

雑談は共通点を探るゲームでもある。

11

QUESTION

クローズドで扉を開け、オープンで広げる

クローズドクエスチョンは、短く答えられるので会話の入口を作りやすい質問です。一方、オープンクエスチョンは、相手が自分の言葉で話せるため、経験や考えまで広げられます。

どちらか一方が正しいのではありません。最初は答えやすく、反応があったら自由に話せる質問へ切り替える。その順番が、尋問にせず会話を育てるポイントです。

種類
特徴
例
クローズド
「はい・いいえ」で答えられる。入口・確認に向く
「映画観ます？」
オープン
自由に答えられる。広げる・深める
「どんな映画が好き？」

NG｜クローズドだけ

美容師映画観ます？

お客様はい。

美容師邦画ですか？

お客様はい。

美容師映画館行きます？

お客様たまに。

→ 尋問になりやすい。

OK｜途中から開く

美容師映画観ます？

お客様結構観ます。

美容師どんな映画好きなんです？

お客様サスペンスです。

美容師何が好きなんです？犯人考える感じとか？

→ 入口は閉じても、その後は開く。

RULE

クローズドで扉を開ける。オープンで中に入る。

12

PICK

相手の答えから「次の扉」を見つける

会話が上手い人は、質問を大量に暗記しているわけではありません。相手の答えに出てきた言葉から、次に進めそうな扉を選んでいます。

新しい質問をゼロから作ろうとすると、自分の頭の中に意識が戻ります。相手が出した言葉を使えば、話題は相手の関心から離れません。「どの言葉に感情が乗っていたか」を見ると、選ぶ扉が分かりやすくなります。

EXAMPLE

「高校の友達と沖縄に行った」→ 高校 / 友達 / 沖縄 / 旅行。どの言葉からでも次に進める。

NG｜情報収集だけ

美容師何泊です？

お客様3泊です。

美容師ホテルどこでした？

お客様那覇です。

美容師何食べました？

→ 答えを受けず、別の情報を取り続けている。

OK｜相手の言葉を拾う

お客様高校の友達と沖縄に行ったんですよ。

美容師高校からずっと仲良いんですか？

お客様もう15年くらいです。

美容師今でも旅行行くくらい仲良いっていいですね。

→ 旅行から人間関係の話へ自然に移った。

KEY

質問を探すのではなく、相手が出した言葉を拾う。

13

FOLLOW UP

フォローアップクエスチョンで会話を育てる

重要なのは質問の数ではなく、相手が答えた内容を「ちゃんと使う」こと。驚きや興味を乗せながら、その答えを起点に次の質問をします。

フォローアップは、会話を深く見せるテクニックではありません。「今の答えを聞いています」という態度を、次の質問で示す方法です。同じ話題に少し長く留まることで、情報ではなく経験や感情が見えてきます。

型
使い方
例
DETAIL
詳しく聞く
「具体的にどういうこと？」
WHY
理由を聞く
「なんでそう思った？」
FEEL
感情を聞く
「その時どうだった？」
NEXT
続きを聞く
「それからどうなった？」
COMPARE
比較する
「前と比べてどう？」

NG｜質問リストを消化する

美容師最近何してます？

お客様ゴルフ始めました。

美容師へえ。旅行とか行きます？

→ 「ゴルフ」という材料を捨てている。

OK｜答えを使う

美容師最近何してます？

お客様ゴルフ始めました。

美容師え、なんで急にゴルフ？

お客様会社の人に誘われて。

美容師やってみたら意外とハマった感じです？

お客様そうなんですよ。

美容師何が面白いんです？

→ 一つの答えから会話が育っている。

質問数のノルマは作らない。短い時間でも、相手の一つの答えを何度も拾い直す方が重要です。

14

DEPTH & WIDTH

話を「縦」に深め、「横」に広げる

深掘りだけが上手い会話ではありません。一つの話題を深くする「縦」と、相手の言葉から関連テーマへ移る「横」を使い分けます。

縦だけを続けると、相手によっては追及されているように感じます。横だけを続けると、話題は増えても理解は深まりません。反応が良い時は縦へ、答えにくそうな時は横へ動くと、会話の圧を調整できます。

方向
イメージ
縦に深める
沖縄 → 何が良かった？ → なぜ？ → どう感じた？
横に広げる
沖縄 → 高校の友達 → 学生時代 → 人付き合い

EASY MOVE

何を聞けばいいか分からなくなったら、「それからどうなったんです？」は強い。ストーリーの続きを自然に引き出せる。

15

DEEPEN

雑談から「感情・価値観」へ一歩深める

天気、映画、食べ物、髪。軽い話題は入口です。そこから、その人が何を好きで、何を大切にしているかへ進んでいきます。

価値観を知りたいからといって、いきなり大きな質問をする必要はありません。事実を聞き、経験を聞き、そこで起きた感情を聞く。その階段を一段ずつ進むと、相手が大切にしているものが自然に見えてきます。

レベル
見るもの
例
1 事実
何が起きた？
「転職した」
2 経験
実際どうだった？
「新しい職場どう？」
3 感情
どう感じた？
「楽しい？不安？」
4 価値観
何を大切にする？
「仕事で一番大事なのは？」

NG｜階段を飛ばす

お客様転職したんです。

美容師人生で一番大事にしてるものって何ですか？

→ 深さはあるが、急すぎる。

OK｜一段ずつ入る

お客様転職したんです。

美容師新しい職場どうです？

お客様楽しいです。

美容師何が一番変わりました？

お客様人間関係ですね。

→ 相手が開いた分だけ、一段進む。

16

PLAY

ふざけた質問でも、価値観まで行けばOK

深い会話＝真面目な話、ではありません。関係性ができていれば、究極の2択やくだらない質問から、その人の性格や価値観が見えることもあります。

• 「最後の晩餐なら何食べる？」

• 「生まれ変わるなら何になりたい？」

• 「タイムスリップするなら過去と未来どっち？」

• 「カレー味のうんこ vs うんこ味のカレー、どっち？笑」

OK｜ふざけて終わらせない

美容師タイムスリップなら過去と未来どっち？

お客様過去かな。

美容師なんで過去なんです？

お客様高校時代が一番楽しかったから。

美容師へえ、どんな高校生活だったんです？

→ 遊びの質問から、思い出・人間関係・価値観へ進める。

CAUTION

初対面で「カレー味のうんこ」は事故る。攻めの接客は距離感を読むところまでセット。

17

EMPATHY

表面的な共感と、深い共感は違う

表面的な共感は、相手が表に出した感情を受け止めること。深い共感は、その感情の後ろにある事情・不安・動機・価値観まで理解しようとすることです。

表面的な共感が悪いわけではありません。まず受け止めることは必要です。そのうえで「何が一番しんどいのか」「本当はどうしてほしかったのか」を確認すると、同じ「嫌」という言葉の奥にある本当の理由へ近づけます。

表面的な共感
深い共感
「仕事行きたくない」→「それ嫌ですよね」
「何が一番しんどい？」→ 背景まで理解する
感情に同調する
なぜその感情が生まれたか想像する
その場で受け止める
動機・目的・事情まで見る

NG｜表面だけ

お客様最近仕事行くの嫌なんですよ。

美容師それ嫌ですよね。分かります。

→ 「仕事が嫌」という表面にだけ共感している。

OK｜感情の奥へ

お客様最近仕事行くの嫌なんですよ。

美容師何が一番しんどいんです？

お客様上司が全部否定してくるんですよ。

美容師仕事そのものより、頑張ってるのに認めてもらえない感じがしんどいんですかね。

お客様そう。それなんですよ。

→ 表面の「仕事が嫌」から、本当の感情に近づいている。

DEPTH

発言 → 感情 → 動機 → 価値観。ここまで見られると、「この人は自分を分かってくれる」に近づく。

18

HARMONY

意見が違っても「調和的」に接する

親しくなるために、何でも同意する必要はありません。共感と同意は別物です。相手の背景を理解しつつ、自分の意見は残していい。

無理に合わせると、その場は丸く収まっても関係は浅いままです。大切なのは、相手の感情や理由を理解したうえで、自分との違いも落ち着いて置くこと。違いがあっても安全に話せる経験が、信頼につながります。

NG｜否定する

お客様俺だったら会社辞めますね。

美容師いや、それは辞めない方がいいですよ。

→ 正しさの勝負になっている。

NG｜無理に合わせる

お客様絶対辞めるべきですよね。

美容師ですよね！絶対辞めた方がいいですよ！

→ 本当は違うと思っているなら、自分が消える。

OK｜違いを残したまま理解する

美容師そこまで嫌だったら辞めたいって思うのは分かります。僕だったらもう少し様子見るかもしれないですけど。

→ 相手の感情は受け取る。でも意見まで捨てない。

KEY

共感と同意は違う。

19

LISTENING

アクティブ・リスニングは「承認 → 深める → 返す」

聞き上手は、相槌が上手い人ではありません。相手の話を受け取り、深め、理解した内容を返す人です。

承認は「今の話を受け取った」と伝えること。深める質問は、背景を理解すること。最後に自分の理解を返すことで、相手は「伝わったかどうか」を確認できます。外れていれば、相手が修正してくれる余地も生まれます。

NG｜相槌だけ

お客様会社辞めようか迷ってるんです。

美容師へえ。そうなんですね。分かります。

→ 聞いてはいるが、理解は深まっていない。

OK｜承認 → 深める → 返す

お客様会社辞めようか迷ってるんです。

美容師結構悩んでそうですね。

美容師何が一番引っかかってるんです？

お客様仕事内容より人間関係がきつくて。

美容師聞いてると、仕事そのものより人間関係の方が大きそうですね。

→ 「聞いている」から「理解している」へ進む。

POINT

理解したつもりで終わらず、理解した内容を言葉にして返す。

20

SELF-DISCLOSURE

自分も少し開く

相手だけに話させ続けると面接になります。自分の経験、感情、失敗、趣味などを少し返すことで、関係は双方向になります。

自己開示の目的は、自分を知ってもらうことだけではありません。「自分だけが話している」という相手の不安を下げ、こちらも同じ会話の中にいると伝えることです。

長く話して主役を奪うのではなく、相手の話とつながる自分の経験を短く出し、また相手へ返します。

NG｜質問攻め

美容師趣味は？

美容師休日は？

美容師仕事は？

→ 相手だけが開示する構造になっている。

OK｜自己開示 → 相手へ返す

お客様最近ジム始めたんです。

美容師いいですね。僕も運動してますけど、始めるまでが一番面倒なんですよね（笑）。何きっかけだったんです？

→ こちらも少し開くことで、相手が話しやすくなる。

VULNERABILITY

完璧な自分だけを見せなくていい。小さな失敗や弱さは、相手が安心して開くきっかけになる。

21

3 SIMPLE RULES

会話の基本はラリー

会話は、どちらか一人が話し続けるものではありません。自分の話を相手へ返し、相手の話を受け取る。その往復を作るために、3つの練習用ルールを使います。

RULE 01

ピンポンルール

目安
自分40：相手60
目的
話しすぎ・聞きすぎを防ぐ

会話はスピーチではなく、卓球のラリーです。

自分ばかり話しても成立しないし、質問だけして相手に話させ続けても成立しません。

自分も話す → 相手に返す → また受け取るという往復を作ります。

NG

「僕この前韓国行って、初日は○○に行って、その次の日は……」

OK

「僕もこの前韓国行ったんですよ。ご飯めちゃくちゃ良かったです。○○さん韓国行ったことあります？」

POINT40：60は絶対的な数字ではありません。「自分ばかりになっていないか」を確認する目安です。

RULE 02

信号機ルール

目安
30秒程度で一度返す
目的
自分語りを防ぐ

人は自分が興味のある話になると、思っている以上に長く話します。

特に美容師は、髪・美容・自分の趣味について詳しいので、説明が長くなりやすい。

そこで、「30秒くらい話したら一度相手に返す」を練習用ルールにします。

EXAMPLE

「これ結構好きなんですよ。○○さんはどうです？」と返す。

POINT話を途中で強制終了するルールではありません。相手が会話に参加できる余白を作るためのルールです。

RULE 03

一時停止ルール

目安
相手が話し終わったら、一呼吸してから返す
目的
「ちゃんと聞いた」を伝える

相手が話し終わった瞬間にこちらが話し始めると、「こっちが話している間、次に言うことを考えていた」ように見えることがあります。

一呼吸置くだけで、「今の話を受け取った」という印象が生まれます。

NG

相手が話し終えた瞬間、「僕もそれあります！」

OK

一呼吸置いて、「それ結構きつかったですね」

POINT間は「気まずい時間」ではありません。相手の話を受け取る時間です。

原稿の会話例

NG｜3分間スピーチ

美容師僕この前沖縄行ったんですけど、まず空港で……（長い）

→ 会話ではなくプレゼンになっている。

OK｜話したら返す

美容師僕もこの前沖縄行ったんですよ。海めちゃくちゃ良かったです。○○さんは旅行だと何するのが好きです？

→ 短く話し、ボールを相手へ返す。

22

READ

心理読解は「心を当てる」ことではない

相手の言葉、表情、声、間、質問、視線から仮説を立てます。ただし、決めつけず、小さく確認し、違えば修正します。

心理読解を「正解を当てる技術」だと思うと、断定が増えます。実際に必要なのは、反応から仮説を作り、相手が否定しやすい小さな言葉で確認することです。

外れることは失敗ではありません。外れた時にすぐ引き、相手の言葉に合わせて理解を更新できることが、安全な会話につながります。

PROCESS

観察 → 仮説 → 小さく確認 → 修正

NG｜決めつける

美容師それ旦那さんとうまくいってないんですね。

→ 相手の内面を断定している。

OK｜仮説として確認する

美容師結構ストレスになってる感じです？

お客様いや、そこまでじゃないですよ（笑）

美容師あ、そこまでではないんですね。

→ 外れたらすぐ修正する。

引ける人ほど、結果的に深いところまで行ける。

23

EMOTIONAL SIGNAL

上級者は「感情が動いた場所」を見る

何を言ったかだけではなく、どこで表情や声が変わったかを見る。そこに、その人が本当に話したいテーマが隠れていることがあります。

人は、重要な言葉だけを強調して話すとは限りません。何気ない一言の時に笑顔が増えたり、声が少し明るくなったり、急に具体的な話が増えたりします。

その変化を見つけたら、決めつけずに一つだけ拾う。話の中心が場所や出来事ではなく、人間関係や感情だったと分かることがあります。

EXAMPLE

お客様沖縄行って、海も良かったんですけど、高校時代の友達と久しぶりに行けたのが一番良くて。

美容師その友達とはずっと仲良いんですか？

→ 本当のテーマは「沖縄」ではなく「友人との関係」かもしれない。

ADVANCED

何を言ったかより、どこで感情が動いたか。

24

CONTINUITY

会話を次回来店につなげる

親密さは一度の会話ではできません。前回の話を覚え、次回に続きを聞くことで、会話は点から線になります。

NG｜毎回ゼロから

美容師最近どうですか？

→ 関係が積み上がらない。

OK｜続きを聞く

美容師この前言ってたプレゼンどうでした？

美容師韓国旅行もう行ってきました？

美容師あの映画、結局観ました？

→ 「覚えている」が信頼になる。

CLOSE

会話の最後に「また次回聞かせてください」と言えると、次回への伏線になる。
